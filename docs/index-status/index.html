読むときの注意
・数字の出どころは Search Console の URL Inspection API です。GSCの「ページ」レポートそのものにAPIは無いため、レポート画面の件数とは一致しません。
・初回観測（未照会→初めて状態が分かった）は「遷移」に数えません。一巡し終わるまでの約8日間、これを混ぜると本来見たい変化がノイズに埋もれるためです。
・APIのクォータが1日2,000URLなので、全14,134URLを毎日は照会できません。最終照会が古い順に1日1,800件ずつ回し、約8日で一巡します。「本日の遷移」は、その日に照会した約1,800件の中で変化したものです。
・照会に失敗したURLは前回の値を保持します（上書きして値を失わないため）。
・元データ：index_status/state.csv（最新状態）／index_status/changes/（日次の遷移）／index_status/daily.csv（日次件数）
